서비스 개요

본 서비스는 고교학점제 시대, 학생들이 자신의 진로에 대해 초기 기획 단계부터 쉽고 빠르게 접근할 수 있도록 돕습니다. AI의 도움으로 구체적인 교과 선택·독서 활동·생기부 키워드·대학 진학 정보 로드맵을 통합 제공합니다.

데이터 기반의 맞춤형 추천을 통해 학생들은 자신에게 맞는 진로를 더 쉽게 찾아나가고, 교사들은 AI 보조 교사를 활용하여 진로 상담의 질을 향상하고 업무 부담을 경감할 수 있습니다.

데이터 출처

  • 과목 정보 (나이스/학교알리미 API): 전국 고등학교의 표준 교육과정 및 선택 과목 상세 설명 데이터를 연동하여 제공합니다.
  • 도서 정보 (국립중앙도서관/API): 추천된 도서의 저자, 줄거리, 소장 여부 등을 실시간으로 검색하여 상세 정보 및 링크를 제공합니다.
  • 대학/학과 정보 (대학알리미 API): 각 대학 및 학과별 핵심 역량, 권장 이수 과목 기준 등 진로 설계에 필요한 데이터를 활용합니다.

기술 스택

핵심 AI 모델: Gemma 4 (GGUF 양자화)

Google의 Gemma 4 모델을 GGUF Q5_K_P로 양자화하여 로컬에서 직접 실행합니다. 한국 교육과정 추론에 특화된 시스템 프롬프트와 ChatML 포맷으로 구조화된 JSON 출력을 유도합니다.

로컬 추론: llama-cpp-python + RadixAttention 유사 구현체

GGUF 모델을 llama-cpp-python으로 직접 실행하며, vLLM의 RadixAttention과 동일한 원리인 Radix Tree 기반 KV 캐시 공유로 반복 프리픽스의 토큰 재계산을 생략합니다. 추론 패스(과목·대학·키워드)별 독립 트리 3개를 운용하여 컨텍스트 오염을 방지하고, asyncio Lock 큐로 동시 요청을 직렬화하여 단일 GPU 환경에서도 안정적으로 서비스합니다.

정확성 확보: 공공 API 컨텍스트 주입

NEIS(나이스)에서 실제 시간표·개설 과목을, 대학알리미에서 학과 정보를, 국립중앙도서관 API에서 실존 도서를 실시간으로 조회하여 LLM 프롬프트에 직접 주입합니다. 모델이 지어내는 허위 정보 대신 검증된 공공 데이터만을 근거로 답변을 생성하여 환각을 최소화합니다.
